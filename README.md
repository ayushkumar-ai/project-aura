# Project AURA

AURA is an AI system designed around explicit orchestration,
controlled memory, model interfaces, tools, policy enforcement,
observability, and evaluation.

## Status

Pre-implementation specification complete.
Core implementation in progress.

## Architecture

AURA is organized around:

- Core orchestration
- Model providers
- Context management
- Memory
- Tools
- Policy and safety
- Evaluation
- Testing

## Project Structure

The repository follows the architecture defined in the AURA
pre-implementation specification documents.

## Development Principle

Build incrementally:

Design -> Implement -> Test -> Evaluate -> Improve
